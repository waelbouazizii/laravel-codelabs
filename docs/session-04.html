MVC, deuxième lecture : le côté Vue 15 min

En session 01, MVC était un tableau à trois lignes. Aujourd'hui, vous construisez la couche Vue pour de bon. La figure suit une requête vers /posts dans votre projet.

Le tableau PHP de PostController joue le rôle du Modèle : il fournit les données. MVC est une répartition des rôles, pas une liste de dossiers. En session 05, seule la boîte en pointillés changera ; vos vues et vos composants resteront les mêmes.

Du fichier Blade à la page HTML

Blade est un moteur de templates : du HTML avec des emplacements que le serveur remplit. Le navigateur ne voit jamais de Blade.

La fonction e() échappe le HTML : c'est elle qui se cache derrière {{ }}.

Penser en composants

Sans composant, la barre de navigation, les boîtes d'information et les cartes d'articles sont recopiées dans chaque vue. Une correction doit alors être faite dans chaque fichier, et un oubli suffit à rendre le site incohérent.

Un composant écrit ce HTML une seule fois. Chaque page l'utilise comme une balise et lui transmet ses données.

Aide-mémoire : anatomie d'un composant anonyme

Ce tableau sert de référence pendant les étapes : inutile de le mémoriser maintenant.

ÉlémentRôle
Fichierresources/views/components/post-card.blade.php s'utilise avec la balise <x-post-card />.
@propsDéclare les entrées du composant, avec une valeur par défaut facultative : @props(['type' => 'info']).
Prop statique ou dynamiquetype="info" transmet le texte info ; :post="$post" évalue l'expression PHP et transmet le tableau.
{{ $slot }}Reçoit le contenu placé entre la balise ouvrante et la balise fermante.
Slot nommé<x-slot:title> remplit une zone supplémentaire, disponible dans la variable $title.
$attributesContient les classes et attributs ajoutés par la page appelante, fusionnés sur l'élément racine.
request()->routeIs('posts.*')Vrai si le nom de la route courante correspond ; le joker * couvre posts.index, posts.archive et posts.show.

Anonyme signifie qu'il n'y a pas de classe PHP : le composant est un simple fichier Blade.

Quiz éclair

Dans votre projet, aujourd'hui, où se trouve le « M » de MVC ?

MVC répartit des rôles. Le tableau PHP joue le rôle du Modèle jusqu'à la session 05 ; la vue, elle, ne changera pas.

Quelle différence entre <x-card :post="$post"> et <x-card post="$post"> ?

Avec les deux-points, l'expression PHP est évaluée et le tableau (ou l'objet) est transmis ; sans eux, le composant reçoit le texte littéral $post.

Un article a pour titre <script>alert(1)</script> et la vue contient {{ $post['title'] }}. Que voit le visiteur ?

{{ }} transforme les chevrons en texte visible : le navigateur les affiche au lieu de les exécuter. Rien n'est supprimé.

<?php

namespace App\Http\Controllers;

{
    public function index(): View
    {
        return view('posts.index', [
            'heading' => 'Tous les articles',
            'posts' => $this->posts(),
        ]);
    }

    public function archive(string $year): View
    {
        $posts = array_filter(
            $this->posts(),
            fn (array $post) => $post['year'] === (int) $year
        );

        return view('posts.index', [
            'heading' => 'Articles de '.$year,
            'posts' => $posts,
        ]);
    }

    public function show(string $slug): View

        $post = $this->posts()[$slug] ?? null;
