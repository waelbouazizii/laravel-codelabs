Session 03 - Semaine 2 - Session A

Prérequis et objectifs

Objectifs

  1. Définir des routes avec paramètres, contraintes (where, whereNumber) et noms, et générer des URL avec route().
  2. Regrouper des routes avec prefix et name, et les inspecter avec route:list.
  3. Déplacer la logique des closures vers des contrôleurs avec la syntaxe [Controller::class, 'methode'].
  4. Construire un layout en composant Blade anonyme (x-layout) avec $slot et un slot nommé title.
  5. Charger Tailwind avec @vite.

Prérequis

  • Session 02 terminée : dépôt mini-cms sur GitHub, tags lab-01 et lab-01b, git status propre.
  • Node.js LTS et npm : obligatoires à partir de cette session (le layout charge Tailwind avec Vite).

Le trajet d'une requête aujourd'hui 15 min

  1. Le navigateur demande une URL.
  2. routes/web.php trouve la route : URI, contrainte, nom.
  3. La méthode du contrôleur prépare les données.
  4. La vue Blade affiche ces données.
  5. Le layout x-layout entoure la vue (en-tête, navigation, pied de page).
  6. Laravel renvoie la réponse HTML au navigateur.

Vocabulaire

TermeDéfinition
URILe chemin demandé, par exemple /posts/routes-et-controleurs
ParamètreSegment variable {slug}, transmis à la méthode
ContrainteRègle sur un paramètre (whereNumber, where) ; si elle échoue, la route ne correspond pas et Laravel répond 404
NomIdentifiant stable (posts.show) utilisé par route() ; l'URI peut changer sans casser les liens
ContrôleurClasse de app/Http/Controllers qui regroupe les actions d'un même sujet
LayoutComposant resources/views/components/layout.blade.php ; {{ $slot }} reçoit le contenu de la page
Slot nomméZone supplémentaire (title) remplie avec x-slot:title

À retenir

Pourquoi ? Un contrôleur regroupe les actions d'un même sujet ; web.php redevient un sommaire lisible. [PageController::class, 'about'] est un tableau PHP vérifiable par l'éditeur, contrairement à l'ancienne chaîne 'PageController@about'.

Erreurs fréquentes : Target class [PageController] does not exist. : la ligne use App\Http\Controllers\PageController; est absente de web.php. Call to undefined method App\Http\Controllers\PageController::about() : le nom de méthode diffère entre web.php et le contrôleur.

Lecture seule : l'alternative classique @extends

Ne créez pas ces fichiers : ils servent à reconnaître cette syntaxe dans d'anciens projets.

À retenir

Pourquoi ? Un composant anonyme est un simple fichier de resources/views/components : x-layout désigne layout.blade.php. Tout ce qui est entre les balises arrive dans $slot, et x-slot:title remplit la variable $title. @vite insère les balises CSS et JS servies par Vite.

Erreurs fréquentes : Vite manifest not found at: suivi d'un chemin qui se termine par build/manifest.json : composer run dev ne tourne pas dans le Terminal 1. Unable to locate a class or view for component [layout]. : fichier mal nommé ou hors du dossier components. Page sans style : vous êtes sur le port 5173, ou les classes ont une faute de frappe.

class PostController extends Controller
{
    private function posts(): array
    {
        return [
            'decouvrir-laravel-13' => [
                'title' => 'Découvrir Laravel 13',
                'year' => 2026,
                'body' => 'Laravel 13 simplifie la structure du projet : la configuration des middlewares et des exceptions se fait dans bootstrap/app.php.',
            ],
            'routes-et-controleurs' => [
                'title' => 'Routes et contrôleurs',
                'year' => 2026,
                'body' => 'Une route associe une URL à une méthode de contrôleur. Le contrôleur prépare les données, la vue les affiche.',
            ],
            'premiers-pas-avec-blade' => [
                'title' => 'Premiers pas avec Blade',
                'year' => 2025,
                'body' => 'Blade est le moteur de vues de Laravel. Les doubles accolades échappent toujours le contenu affiché.',
            ],
        ];
    }

    public function index()
    {
        return view('posts.index', [
            'heading' => 'Tous les articles',
            'posts' => $this->posts(),
        ]);
    }

    public function archive(string $year)
    {
        $posts = array_filter(
            $this->posts(),
            fn (array $post) => $post['year'] === (int) $year
        );

        return view('posts.index', [
            'heading' => 'Articles de '.$year,
            'posts' => $posts,
        ]);
    }

    public function show(string $slug)
    {
        $posts = $this->posts();

        if (! array_key_exists($slug, $posts)) {
            abort(404);
        }

        return view('posts.show', [
            'post' => $posts[$slug],
        ]);
    }
}
