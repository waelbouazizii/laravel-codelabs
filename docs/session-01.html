Attention aux tutoriels anciens

Les tutoriels écrits avant Laravel 11 mentionnent app/Http/Kernel.php, app/Console/Kernel.php, RouteServiceProvider, un fichier routes/api.php présent par défaut, et Laravel Breeze. Rien de tout cela ne s'applique au projet Laravel 13 de ce cours. Le middleware et les exceptions se configurent dans bootstrap/app.php, et routes/api.php n'apparaît qu'après php artisan install:api (S13).

Code complet

Contenu d'un projet neuf. Si votre fichier diffère légèrement, c'est votre fichier qui fait foi.

public/index.php :

<?php

use Illuminate\Foundation\Application;
use Illuminate\Http\Request;

define('LARAVEL_START', microtime(true));

// Determine if the application is in maintenance mode...
if (file_exists($maintenance = __DIR__.'/../storage/framework/maintenance.php')) {
    require $maintenance;
}

// Register the Composer autoloader...
require __DIR__.'/../vendor/autoload.php';

// Bootstrap Laravel and handle the request...
/** @var Application $app */
$app = require_once __DIR__.'/../bootstrap/app.php';

$app->handleRequest(Request::capture());

routes/web.php :

<?php

use Illuminate\Support\Facades\Route;

Route::get('/', function () {
    return view('welcome');
});

view('welcome')Rend resources/views/welcome.blade.php

Introduction

Aucun code n'est fourni : réutilisez les techniques des Étapes 6 et 7.

D1 - Route /version

La route /version renvoie une chaîne du type « Laravel 13.x.x - PHP 8.x.x ».

Indice

app()->version() renvoie la version de Laravel ; la constante PHP PHP_VERSION renvoie la version de PHP.

D2 - Route /heure

La route /heure renvoie une vue heure.blade.php affichant l'heure (format H:i) et la date (format d/m/Y). Comparez avec l'horloge de la salle. En cas d'écart, ouvrez config/app.php, trouvez la clé timezone, mettez-la à 'Africa/Tunis', et rechargez.

Indice

now()->format('H:i').

D3 - Lire une page d'erreur

Renommez temporairement la vue, rechargez /bienvenue, notez le titre du message d'erreur, puis restaurez.

Sauvegarde sur clé USB (recommandé) : arrêtez composer run dev avec Ctrl+C, puis (remplacez E: par la lettre de votre lecteur) :

Bash :

cd /c/dev/prenom-nom
tar --exclude=vendor --exclude=node_modules -czf /e/mini-cms-lab01.tar.gz mini-cms

PowerShell :

Set-Location C:\dev\prenom-nom
tar --exclude=vendor --exclude=node_modules -czf E:\mini-cms-lab01.tar.gz mini-cms
