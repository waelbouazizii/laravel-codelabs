Attention aux tutoriels anciens

Les tutoriels écrits avant Laravel 11 mentionnent app/Http/Kernel.php, app/Console/Kernel.php, RouteServiceProvider, un fichier routes/api.php présent par défaut, et Laravel Breeze. Rien de tout cela ne s'applique au projet Laravel 13 de ce cours. Le middleware et les exceptions se configurent dans bootstrap/app.php, et routes/api.php n'apparaît qu'après php artisan install:api (S13).

À retenir

Pourquoi ? SQLite stocke toute la base de données dans un seul fichier (database/database.sqlite) : aucun serveur à installer ni à démarrer, ce qui est idéal pour apprendre. En production, on utilise souvent MySQL ou PostgreSQL, et Laravel permet de changer de base en modifiant .env. Le fichier .env contient la configuration réelle de votre poste (clé secrète, base de données) et n'est jamais versionné. Le fichier .env.example est le modèle versionné, sans secrets, que l'on copie pour créer .env.

Erreurs fréquentes : could not find driver pendant l'installation : l'extension pdo_sqlite est absente (vérifiez avec php -m, voir l'Étape 1). Un dossier mini-cms incomplet après une coupure réseau : relancez laravel new mini-cms --force.

Ajouter deux routes closures qui renvoient du texte.

Commandes

Bash et PowerShell (identique) :

Code complet

Contenu complet de routes/web.php :

<?php

use Illuminate\Support\Facades\Route;

Route::get('/', function () {
    return view('welcome');
});

Route::get('/bonjour', function () {
    return 'Bonjour MDW3 ! Voici ma première route Laravel 13.';
});

Route::get('/bonjour-court', fn () => 'Même résultat, écrit avec une fonction fléchée.');

Route::get(url, closure) : la chaîne renvoyée devient le corps de la réponse ; les deux routes ne diffèrent que par la syntaxe ; pas besoin de redémarrer le serveur, car PHP relit les fichiers à chaque requête.

Résultat attendu

/bonjour et /bonjour-court affichent chacune leur phrase.

Vérification

route:list liste bonjour et bonjour-court. Ctrl+U (code source de la page) montre uniquement le texte brut, sans HTML.

À retenir

Pourquoi ? Une route associe une méthode HTTP et une URL : Route::get ne répond qu'aux requêtes GET (et HEAD). Une requête POST vers /bonjour renverrait une erreur 405 Method Not Allowed.

Erreurs fréquentes : Un point-virgule oublié provoque une erreur de syntaxe (ParseError) affichée dans la page. Si le fichier n'est pas enregistré, la route n'existe pas encore et vous obtenez une erreur 404.

Introduction

D1 - Route /version

La route /version renvoie une chaîne du type « Laravel 13.x.x - PHP 8.x.x ».

D2 - Route /heure

La route /heure renvoie une vue heure.blade.php affichant l'heure (format H:i) et la date (format d/m/Y). Comparez avec l'horloge de la salle. En cas d'écart, ouvrez config/app.php, trouvez la clé timezone, mettez-la à 'Africa/Tunis', et rechargez.

Voir un corrigé

Le navigateur envoie GET /heure. public/index.php, seul point d'entrée, charge l'autoloader Composer puis bootstrap/app.php, qui crée l'application et déclare routes/web.php. Le routeur trouve la route /heure dans routes/web.php et exécute sa closure. La closure renvoie la vue resources/views/heure.blade.php, compilée en HTML, et Laravel renvoie cette réponse au navigateur.

Critères de réussite

Git (dans le dossier mini-cms, second terminal)

Bash et PowerShell (identique) :

Seulement si git status affiche « not a git repository » :

git init

Bash et PowerShell (identique) :

git config user.name "Prenom Nom"

git log -1 --format="%an <%ae>"

Utilisez l'adresse de votre compte GitHub, ou celle avec laquelle vous le créerez avant S02 : c'est elle qui relie vos commits à votre profil. Pas d'option --global, car les postes du laboratoire sont partagés. Si git log affiche « does not have any commits yet », c'est normal.

Seulement si git log affiche une autre identité que la vôtre :

git commit --amend --reset-author --no-edit

Bash et PowerShell (identique) :

git add -A
