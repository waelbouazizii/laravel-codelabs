Etape 1 - Presentation

Objectif

Ceci est un modele de codelab. Chaque etape suit la meme structure : objectif, commandes, code complet, resultat attendu et verification. Remplacez ce contenu par celui de la vraie session avant publication.

Commandes

Bash / macOS / Linux :

php artisan --version

PowerShell (postes Windows du laboratoire) :

php artisan --version

Resultat attendu

La commande affiche la version de Laravel installee, par exemple Laravel Framework 13.0.0.

Objectif

Exemple de bloc de code complet dans plusieurs langages, pour verifier que la coloration syntaxique Prism se charge correctement.

Code complet

Modele Eloquent (PHP) :

<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;

class Product extends Model
{
    protected $fillable = [
        'name',
        'price',
        'is_active',
    ];

    protected function casts(): array
    {
        return [
            'is_active' => 'boolean',
            'price' => 'decimal:2',
        ];
    }
}

Route API (JSON de reponse) :

{
  "data": [
    {
      "id": 1,
      "name": "Clavier mecanique",
      "price": "59.90",
      "is_active": true
    }
  ]
}

Requete SQL equivalente :

SELECT id, name, price, is_active
FROM products
WHERE is_active = 1
ORDER BY name ASC;

Quiz éclair

Qu'affiche php artisan --version dans le projet de cette session ?

artisan est l'outil en ligne de commande de Laravel : --version affiche la version du framework, pas celle de PHP ou de Composer.

Dans le modèle Product ci-dessus, que devient la valeur de is_active lue en base ?

La méthode casts() convertit is_active en booléen ; decimal:2 s'applique à price.
